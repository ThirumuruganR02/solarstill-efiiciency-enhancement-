# 🌞 Solar Still Distillation Efficiency Enhancement

A hybrid **Java + Python** project focused on improving solar still distillation efficiency using **mathematical modelling, optimization logic, and data visualization**.

---

## 🚀 Overview

This project simulates and analyzes the performance of a solar still system enhanced with reflective mirrors. It includes:

- A **Java-based optimization program** to compute optimal mirror angles
- A **Python visualization module** to analyze efficiency trends
- A simple mathematical model to estimate efficiency under different solar conditions

---

## 🎯 Key Features

### 🔹 Java Optimization Engine
- Computes optimal mirror angle based on solar incidence
- Estimates efficiency using mathematical logic
- Evaluates multiple solar scenarios
- Identifies best-performing configuration

### 🔹 Python Data Visualization
- Plots solar angle vs efficiency
- Plots mirror angle vs efficiency
- Provides visual comparison of performance trends

---

## 🛠️ Tech Stack

- Java – Core logic and optimization  
- Python – Data visualization  
- Mathematical Modelling – Efficiency estimation

## ⚙️ How It Works

1. User inputs solar incidence angles  
2. Java program calculates:
   - Optimal mirror angle  
   - Estimated efficiency  
3. Results are analyzed across multiple scenarios  
4. Python script visualizes efficiency trends

## ▶️ How to Run

### 🔹 Run Java Optimizer
cd java-optimizer  
javac SolarStillOptimizer.java  
java SolarStillOptimizer  

### 🔹 Run Python Visualization
cd python-visualization  
python efficiency_visualization.py  

> Install dependencies if needed:
pip install matplotlib
